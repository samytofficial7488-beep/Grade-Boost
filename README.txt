GRADE BOOST Website
===================

FILES
- index.html  : Page content and structure
- style.css   : Colours, layout, responsive/mobile styling
- script.js   : Mobile menu, current year, class selection, WhatsApp enquiry form

HOW TO RUN
1. Download and extract grade_boost_website.zip.
2. Keep index.html, style.css and script.js in the same folder.
3. Double-click index.html to open it in your browser.
4. Test the navigation, class cards, and WhatsApp enquiry form.

- Edit index.html to change text, services, class fees, and contact details.

NOTES
- Google Fonts requires an internet connection; the website still works without it using fallback fonts.
- The WhatsApp enquiry form opens WhatsApp with a pre-filled message. The visitor must press Send.
- This is a front-end website only. It does not include a database, student login, or admin panel.
- To make it public, upload the files to a hosting service such as GitHub Pages or Netlify.
